# EPRK-MA 方法规范

算法全名：Event-driven Partition–Routing Random-Key Memetic Algorithm；版本：`EPRK-MA-v0.1-development`。

## 编码与解码

染色体为固定长度 `(u_up,u_low,q1,…,qN)`。边界键用 `floor(u*M)` 映射到上、下边界事件；每个机器人对已分配原子按 `(q_i, atomic_weld_id)` 稳定排序。因此没有缺失/重复修复，也没有搜索期几何切分。每条路线的方向由精确二状态 DP 解码。

## 初始种群

两子种群的初始化比例为：50% 全随机、20% 工作量平衡事件、15% 零连续/同父相邻优先、15% 最近或最远构造。默认种群 60；受控竞赛后候选使用 40。

## 全局搜索

采用偏置随机键遗传：精英比例、突变体比例和精英键继承概率分别为候选画像中的 0.15、0.15、0.70；两个子种群；每 40 代迁移 2 个精英；停滞 100 代重启。突变包含随机重置、高斯扰动、边界事件跳转和连续键块扰动。

## 局部搜索

事件邻域按 `±1,±2` 首改善。路线邻域只处理关键机器人，候选上限 12，包括 relocate、swap、2-opt、零连续链和同父相邻链。局部搜索只用于精英，最多接受 30 次改善。每个完整候选请求都消耗一个 Primary，不隐藏 ALNS、regret-2 或全枚举工作。

## 缓存与增量复用

赋值缓存键为事件索引对；表型缓存键为两个事件索引和四条有序原子 ID 路线，不含浮点随机键。路线缓存键为有序原子 ID。表型缓存命中仍消耗 Primary，缓存仅减少 CPU。边界或路线局部变化时，未变化路线通过精确路线缓存复用；完整重算测试证明聚合结果一致。

## 预算、随机性与输出

Primary 定义为一次完整系统候选评价请求，包括表型缓存命中。预算模式精确停止，时间模式只在完整候选之间停止。所有随机操作由单一 `random.Random(seed)` 驱动。输出包含事件、边界、四路线、方向、原始/归一化指标、Primary、缓存、路线评价、方向 DP、时间和工作放大。
